# Mein Profil: Claude Code schreibt in deiner Stimme

Ein Claude-Code-Skill, der dein persönliches Profil anlegt: Thema, Zuschauer, deren Worte, deine Stimme, dein Angebot und echte Belege. Andere Content-Skills lesen es, damit sie nach dir klingen und du dich nicht jedes Mal neu erklären musst.

## Was du bekommst

- Ein kurzes Gespräch in drei Runden.
- Die Datei `~/.claude/mein-profil.md`. Sie liegt nur auf deinem Rechner.
- Zum Ändern startest du den Skill einfach noch einmal.

## Installieren

1. Oben rechts auf **Code** und dann **Download ZIP** klicken. ZIP entpacken.
2. Im entpackten Ordner liegt der Ordner `mein-profil`. Kopiere genau diesen Ordner in deinen Skills-Ordner:
   - Windows: `C:\Users\<dein-name>\.claude\skills\`
   - Mac: `~/.claude/skills/`

   Gibt es den Ordner `skills` noch nicht, leg ihn an. Danach liegt die Datei unter `.claude/skills/mein-profil/SKILL.md`.
3. Claude Code neu starten.

## So benutzt du ihn

Tippe `/mein-profil` oder sag es einfach in deinen Worten, zum Beispiel:

> Leg mein Profil an.

## Was du brauchst

- Nur [Claude Code](https://claude.com/claude-code).

## Gut zu wissen

- Der Skill erfindet keine Zahlen oder Ergebnisse. Was er nicht weiß, steht in `[eckigen Klammern]`. Füll diese Stellen vor dem Veröffentlichen mit echten Angaben.
- Das Ergebnis speichert er als Datei in dem Ordner, in dem du Claude Code gestartet hast.
